# Publication

## Fold in what the first installs teach
- area: Publication / Field test
- when: Open
- status: Open

Every install that stalls is a documentation bug, not a user error. The "Install
stall" issue template is the record: where someone stopped, what they expected, what
the repository told them. What that teaches goes back into `GETTING-STARTED.md` and
the templates.

## Re-measure on a larger memory base
- area: Publication / Evidence
- when: Open
- status: Not started

`EVIDENCE.md` is one operator, 69 facts, three task types, nine sessions per
condition. The titles tier lost on first-attempt hits at that size and may win at a
larger one. Re-run `measure.py` when the base is materially bigger, and publish the

## Make the repository public
- area: Publication / Release
- when: 2026-09-21
- status: Done
- done: 2026-09-21

Published after a full read of all 129 files for anything naming a real person,
business, client, path or machine. The internal build plan and the raw measurement
files were removed rather than sanitized: they were a private project journal and a
folder-by-folder inventory of a working business, and editing them line by line
would have left nothing a public reader wants. `EVIDENCE.md` is the summary that
survives, and `measure.py` reproduces its numbers on any workspace.
