# Quotes — mirror index of `~/Projects/Fernwood Landscaping/Quotes/`

Hand-maintained. A job folder is `YYYY-MM-<customer-slug>/` with `site-visit.md`
(filled checklist), `quote.md` (generated from `Templates/quote.md`, never edited),
and `cover-note.md` (draft; Maya sends). A folder suffix marks status: none = open,
`-won`, `-lost`, `-expired`.

## Folders
- `2026-09-hollis-patio/` — 14 by 18 patio, base and drainage recorded 2026-09-11, quote sent by Maya 2026-09-12, open
- `2026-09-ferris-wall-lost/` — retaining wall; quoted 2026-09-05 without the checklist, redone 2026-09-09, lost on price
- `2026-08-marlow-walkway-won/` — flagstone walkway, done 2026-08-28; the reference job for walkway quotes

## Rules for this folder
- No quote without `site-visit.md` filled ([[reference_hardscape_quote_checklist]]).
- The quote file is generated; a change goes in `Templates/quote.md` or the generator.
